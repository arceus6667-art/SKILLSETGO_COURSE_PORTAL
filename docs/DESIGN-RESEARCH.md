# LearnTube reference study and Skill Set Go redesign

Reviewed 24 November 2026.

Public reference: https://learntube.ai/ and its linked certification product, https://certified.learntube.ai/.

The review covered the rendered homepage, sign-in and registration entry points, career positioning, feature sections, skill categories, certification promotion, pricing entry points, FAQ/support links, and certification category-to-skill selection. Account-only learning screens, payment completion, and internal administration were not accessible and are not claimed as reviewed.

Useful patterns adapted to this product:

- Put the learner's goal before the catalogue. Five goal choices narrow the twelve existing domains using explicit, deterministic topic mappings.
- Give each domain a recognizable visual cover, category, summary, content count, and clear destination.
- Keep learning and direct assessment as two visible pathways while preserving consent, attempts, timer, and accessibility rules.
- Put the learner's actual next step first: resume an active assessment, continue an enrolled path, or find a first domain.
- Connect assessment results, free reports, and optional documents in one visible journey with accurate prices.
- For administrators, show content and question-bank readiness and links to outstanding support/payment work, calculated from actual records.

Skill Set Go retains its official logo, navy/gold brand, twelve domains, User/Admin roles, existing content, permissions, pricing, and backend. Layouts, copy, and code were created for Skill Set Go. No LearnTube logos, testimonials, learner counts, employer endorsements, placement guarantees, rewards, or proprietary assets were imported. No new AI, placement, resume, or WhatsApp integration is implied.
